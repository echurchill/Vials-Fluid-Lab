# Fluid Lab audio sources

The four water recordings in this directory are derived from **40 CC0 water / splash / slime SFX** by OpenGameArt user **rubberduck**.

- Source page: https://opengameart.org/content/40-cc0-water-splash-slime-sfx
- License: CC0 1.0 Universal — https://creativecommons.org/publicdomain/zero/1.0/
- Retrieved: 2026-10-12
- Original archive SHA-256: `7cd39abb49d4362a37ba18dc0e454c7dc1d08029d4e5b683149046bc237b2eba`

| Bundled asset | Original recording | Use |
| --- | --- | --- |
| `pour-stream-cc0.wav` | `loop_water_02.ogg` | Continuous pouring stream |
| `receiving-water-cc0.wav` | `loop_water_03.ogg` | Liquid landing in the receiving vessel |
| `pour-start-cc0.wav` | `splash_09.ogg` | Pour-start transient |
| `pour-tail-cc0.wav` | `splash_02.ogg` | Pour-ending splash/tail |

The recordings were decoded to mono 48 kHz PCM WAV, level-balanced for the in-game layered mixer, and given short boundary fades. Loop assets also received a short end bridge so they repeat without a click. No attribution is required by CC0; this manifest is retained for provenance.

# Lab-native helper vessels — September 23

## Player experience

- Sorting Lab, Sorting Course and Endless Sorting can add up to two optional helpers from the board toolbar.
- Each helper begins as a one-unit **tea cup**, upgrades to a two-unit **coffee mug**, and then to a three-unit **water jug**. Three units is the hard maximum.
- Helpers accept and pour matching material through the ordinary Lab rules. A pour involving a helper counts as a move; adding or upgrading one does not.
- Adding and upgrading are still Undoable and saved. Reset removes the helpers with the rest of the current attempt.
- A helper never counts as a completed target. Every helper must be completely empty before the board can be won, and the board explains that requirement if it is the remaining blocker.
- Distinct bodies and glass handles identify all three sizes in Classic, 2D Fluid and 3D Fluid. The artwork is generated by the existing presentation code rather than imported imagery.

## Shared-engine behavior

- Helpers are first-class `LabBoardState` containers with stable indices, capacities, roles and save metadata. No Original-game controller or asynchronous flow was adopted.
- Stable parcel identity means Discovery knowledge follows liquid into and back out of a helper.
- The solver and hint route include helpers and require them to be empty at the goal.
- Helper roles participate in search-state canonicalization, preventing an ordinary vial and a helper of the same capacity from being treated as interchangeable.
- Concurrent reservations use the existing projected-state capacity rules, including compatible shared-receiver pours into a larger helper.
- Game history records whether an action counts as a move. This preserves ordered Undo while keeping helper add/upgrade actions out of the move counter.
- An empty helper remains in the solved state, providing the durable “helper assistance used” signal for later mastery/scoring work without imposing a penalty now.

## Validation

- The focused Sorting Course suite covers add, both upgrades, maximum capacity, ordered Undo, zero move-cost configuration, save/restore, required-empty completion, hint recovery, concurrent capacity reservations and Discovery identity.
- All 25 frozen Sorting Course levels remain source-matched and solvable, including the five Discovery checkpoints.
- All 18 established cross-lab/presentation concurrency cases plus density, Discovery and machine exclusivity remain green.
- Vessel presentation validation covers the three helper silhouettes, renderer cache changes and successful Classic/2D/3D offscreen renders. The tea cup, mug and jug captures were visually inspected.
- macOS Debug and the final signed macOS/iOS Release builds pass.

## Deliberate scope

Helpers are not offered in Valve Lab or the experimental target/apparatus labs yet. That keeps this first release on the pure sorting rules where the mechanic is understood. Expanding them should be an explicit design decision after tester feedback rather than an automatic consequence of shared model support.
